Grounding — what Sofapaint already reaches

CW Import · OMS · PID

Confirmed during this pass: CW Import is built in and gives per-order depth; this database gives whole-catalog breadth. The modeling loop uses both.

OMS

Product & measurement search

src/modules/ui/cw-import-ui.ts searches by name, code or PID via /api/integrations/cw/measurements/search → OMS at cw40.comfort-works.com, with version + style options per product.

Measurements

QC measurements & patterns

Imports measurement rows (value, section, pieces, skirt) and product_components pattern sizes — seat/back/accent cushion W×H×D and quantities, already parsed by the 3D adapter.

Images

PID image service

Production images resolve from cw-pid-qylyewlgca-uc.a.run.app and the pid-storage GCS bucket, proxied through /api/integrations/cw/measurements/image-proxy.

3D bridge

fromCw() → SofaDocument

src/modules/sofa3d/adapters.ts turns an imported payload into an editable 3D document: overall W/D/H, seat & back counts, per-cushion sizes, accent pillows, single-arm modules.
